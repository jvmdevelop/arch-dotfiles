# rvoxel-ai

Lightweight Image-to-Voxel Generator powered by Rust and Burn framework.

## Overview

rvoxel-ai is a lightweight deep learning model that converts 2D images into 3D voxel representations, which can be exported to the rvoxel-dsl format for further processing into 3D models (OBJ, STL, etc.).

## Features

- **Lightweight Architecture**: Optimized for low-spec systems and notebooks
- **CNN-based Model**: Efficient convolutional neural network for image-to-voxel conversion
- **rvoxel-dsl Integration**: Direct export to rvoxel-dsl format
- **Memory Efficient**: Small batch sizes and optimized for CPU training
- **Easy to Use**: Simple command-line interface

## Quick Start

### Installation

```bash
cd rvoxel-ai
cargo build --release
```

### Basic Usage

Generate voxel from image:

```bash
./target/release/rvoxel-ai input.png output.vdsl 0.5
```

Parameters:
- `input.png`: Path to input image
- `output.vdsl`: Output rvoxel-dsl file
- `0.5`: Threshold for voxel generation (optional, default 0.5)

### Convert to 3D Model

After generating the `.vdsl` file, use rvoxel-dsl to convert to 3D formats:

```bash
cd ../rvoxel-dsl
cargo run ../rvoxel-ai/output.vdsl output.obj
```

## Architecture

### Model Design

The model uses a lightweight CNN architecture:

1. **Input**: 128x128 RGB images
2. **Encoder**: 4 convolutional layers with ReLU activation
3. **Bottleneck**: Adaptive pooling to 4x4x256 features
4. **Decoder**: Fully connected layer to voxel grid
5. **Output**: 32x32x32 voxel grid with sigmoid activation

### Memory Optimization

- Small voxel sizes (16-32 voxels per dimension)
- Minimal batch sizes (1-4 samples)
- CPU-first training with optional GPU acceleration
- Efficient data loading and preprocessing

## Training

### Synthetic Data Training

For quick testing and development:

```bash
cargo run --example train_example
```

This creates synthetic voxel shapes (cube, sphere) and trains the model on them.

### Custom Training

Prepare your dataset:
1. Images in any common format (PNG, JPG, etc.)
2. Corresponding voxel data (32x32x32 binary grids)

Then run:

```rust
use rvoxel_ai::lightweight_trainer::LightweightTrainer;

// Create trainer with memory-efficient config
let mut trainer = LightweightTrainer::new(model_config, training_config, device);

// Train on your data
trainer.train_from_examples(&image_paths, &voxel_targets)?;
```

## Configuration

### Model Config

```rust
ModelConfig {
    voxel_size: 32,      // Size of voxel grid (32x32x32)
    max_voxels: 1000,    // Maximum number of voxels
}
```

### Training Config

```rust
TrainingConfig {
    learning_rate: 0.001,
    epochs: 50,
    batch_size: 4,       // Small for memory efficiency
    voxel_size: 32,
    threshold: 0.5,
}
```

## Performance

### Memory Requirements

- **Training**: ~2GB RAM for 32x32x32 voxels
- **Inference**: ~500MB RAM
- **Storage**: ~10MB for trained model

### Training Time

- **CPU (Intel i5)**: ~5 minutes for 20 epochs
- **GPU (GTX 1650)**: ~1 minute for 20 epochs

## Examples

### Command Line

```bash
# Generate with default threshold
rvoxel-ai character.png character.vdsl

# Generate with custom threshold
rvoxel-ai character.png character.vdsl 0.3
```

### Programmatic

```rust
use rvoxel_ai::inference::InferenceEngine;

let engine = InferenceEngine::new(model, device, 0.5);
let voxel_object = engine.generate_from_image("input.png", "my_object")?;
voxel_object.save_vdsl("output.vdsl")?;
```

## Integration with rvoxel-dsl

The generated `.vdsl` files use the rvoxel-dsl format:

```
// Voxel Object: character
// Generated by rvoxel-ai

point 0 0 0 1.0
point 1 0 0 1.0
point 0 1 0 1.0
...
```

This format can be processed by the rvoxel-dsl tool to generate:
- OBJ files for 3D modeling software
- STL files for 3D printing
- Other 3D formats
